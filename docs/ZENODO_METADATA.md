## Description

This collection organizes and preserves a working series of technical notes on scientific Python for engineering and multiphysics research. Its central aim is to connect mathematical meaning to numerical objects, executable operations, and explicit checks of the result, rather than to catalogue package functions alone.

The revised English edition contains 15 executable Jupyter notebooks covering P0–P13, including a short field introduction (P5A) and an expanded treatment of finite-difference stencils and discrete operators (P5B). Topics include Python computational grammar; NumPy shape, axis, indexing, broadcasting, vector and tensor operations; fields and grids; vectorization; dense and sparse linear algebra; nonlinear equations; ODE integration; optimization and least squares; interpolation, integration, differentiation; and plotting, tabular data, and verification workflows. Wood science supplies motivating examples, while the methods are broadly applicable to scientific computing.

The English explanations are adapted and expanded from the supplied Korean notes. Original code examples are retained with documented repairs, and the source notebooks are preserved unchanged in a provenance archive. The package includes HTML exports, a reading guide, tested dependency versions, citation metadata, an execution script, and a numerical review and execution report.

The edition emphasizes the distinction between code execution, solver convergence, numerical verification, parameter identifiability, physical validation, and practical prediction. Synthetic data and wood-related constitutive examples are instructional; this resource does not report new experimental validation. English adaptation and review were prepared with AI assistance, with author responsibility retained by Wook Kang.
